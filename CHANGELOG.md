# Changelog

All notable changes to the Kolia project will be documented in this file.

## [1.4.0] - 2024-02-02
### Added
- **Georgian Language Support**: Added comprehensive Georgian documentation and UI strings.
- **Project Architecture Documentation**: Visual tree added to README for better developer onboarding.
- **Shorebird Integration**: Implemented Over-The-Air (OTA) updates for seamless bug fixes without re-installing.
- **Enhanced BTK Forms**: Improved soil classification logic and dynamic field rendering.

### Changed
- **Documentation Refactor**: Completely rewrote README in a first-person narrative to better reflect project ownership.
- **Security**: Hardened `.gitignore` to ensure `google-services.json` and API keys are never leaked.

### Fixed
- **Sync Logic**: Resolved edge cases in SQLite-to-Firebase synchronization when handling large image attachments.
- **Git Sync**: Fixed branch divergence issues on the main repository.
